# PDF 목차 생성기 · 웹

**[웹 도구 열기](https://cloudmate37.github.io/pdf/)**

PDF를 서버에 업로드하지 않고 브라우저에서 목차와 한국어·영어 OCR 텍스트를 추가합니다. Mac·Windows의 최신 Chrome·Edge·Safari가 대상입니다.

## 사용

1. PDF를 선택하거나 화면으로 끌어놓습니다. 여러 파일을 순차 처리할 수 있습니다.
2. **목차 생성**, **OCR**을 원하는 대로 선택합니다. 기본값은 목차 생성만 선택입니다.
3. **처리 시작**을 누르고 이 탭을 열어 둡니다. 파일별 단계와 페이지 진행률이 표시됩니다.
4. 완료된 파일의 **다운로드**를 눌러 `<원본명>_처리완료.pdf`를 저장합니다.

| 선택 | 처리 방식 |
| --- | --- |
| 목차 생성만 | 구조 태그 → 텍스트·글자 크기·위치·번호 체계를 분석해 장·절 목차를 생성합니다. OCR은 실행하지 않습니다. |
| OCR만 | 텍스트가 전혀 없는 페이지를 인식해 검색·복사용 텍스트를 추가합니다. 기존 목차는 유지합니다. |
| 둘 다 | OCR 후 목차를 생성하며 전체 처리·검증이 성공한 결과만 제공합니다. |

유효한 내장 목차가 있으면 목차 생성만 건너뜁니다. 이미 텍스트가 조금이라도 있는 페이지는 OCR하지 않습니다. 빈 페이지에는 텍스트를 추가하지 않습니다. 바꿀 내용이 없으면 다운로드를 만들지 않습니다. 목차는 최대 장–절 두 단계로 생성하며, 기존의 더 깊은 목차는 그대로 보존합니다.

원본은 덮어쓰지 않습니다. 오류가 난 파일은 결과를 제공하지 않고 다음 파일을 처리합니다. **작업 취소**는 현재·대기 작업을 중단하며 이미 완료된 결과는 유지합니다. 실패·취소한 파일은 **다시 대기**로 재시도할 수 있습니다.

## 개인정보와 한계

- PDF 내용·파일명·처리 결과는 서버로 전송하거나 브라우저 영구 저장소에 저장하지 않습니다. 처리 기록도 메모리에만 있습니다. 탭을 닫으면 아직 다운로드하지 않은 결과가 사라집니다.
- 웹 파일·OCR 모델·글꼴은 GitHub Pages에서 불러옵니다. OCR 관련 자산은 OCR이 필요한 경우에만 요청합니다. 외부 CDN·추적기를 사용하지 않습니다.
- 암호화·서명 PDF는 수정하지 않습니다. 페이지 수·크기·회전·크롭·주석·기존 목차·텍스트와 모든 페이지의 렌더링을 검증한 뒤 다운로드를 제공합니다.
- OCR 엔진의 메모리 오류가 발생하면 새 엔진과 작은 페이지 이미지로 한 번 다시 인식합니다. 복구 후에도 전체 보존 검증을 통과해야 결과를 제공합니다.
- 브라우저 메모리·성능에 따라 큰 문서는 시간이 오래 걸리거나 처리되지 않을 수 있습니다. 페이지 이미지를 한 장씩 해제하지만 원본·결과 PDF 전체를 메모리에 보유해야 합니다.
- OCR·제목 인식 품질은 문서에 따라 다릅니다. Apple Vision·PDFKit·OpenDataLoader·Docling을 사용하는 Mac 앱과 동일한 품질·목차 개수를 보장하지 않습니다. 계층을 신뢰할 수 없으면 결과를 만들지 않습니다.
- 일부 특수 색상·투명도 필터는 Worker에서 안전하게 검증할 수 없어 처리하지 않습니다.
- 지원 기기에서 사용해도 손상된 PDF나 렌더러가 지원하지 않는 기능 때문에 검증이 실패할 수 있습니다. 원본 파일은 변경되지 않습니다.
- 서버, 로그인, 수동 목차 편집, 원본 덮어쓰기, 폴더 감시, 중단 후 재개 기능은 없습니다.

## 개발

Node.js 22.12 이상과 pnpm 10.20을 사용합니다. Python이나 Mac 전용 도구는 실행에 필요하지 않습니다.

```sh
pnpm install --frozen-lockfile
pnpm assets
pnpm dev
# http://127.0.0.1:5173/pdf/
```

```sh
pnpm check
pnpm test
pnpm build
pnpm exec playwright install chromium webkit
pnpm test:e2e
```

`pnpm assets`는 라이브러리의 Worker·WASM·CMap을 복사하고, SHA-256으로 고정된 OCR 모델과 Nanum Gothic 글꼴을 다운로드합니다. 생성된 `public/vendor/`와 `dist/`는 Git에 포함하지 않습니다. `scripts/assets-lock.json`의 체크섬이 맞지 않으면 빌드를 중단합니다.

## GitHub Pages 배포

저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 설정합니다. `main`에 푸시하면 타입 검사·단위 테스트·Chromium/WebKit 통합 테스트를 통과한 후 Pages에 배포합니다. PR에서는 검사만 실행합니다.

서비스 경로는 `/pdf/`이며, 저장소 이름을 바꾸면 `vite.config.ts`의 `base`, HTML 아이콘 경로와 문서 링크를 함께 변경하세요. 배포 결과물에는 실행에 필요한 OCR 모델·글꼴·WASM이 모두 포함됩니다.

## 구성과 라이선스

PDF.js(읽기·렌더링), Tesseract.js(한국어·영어 OCR), pdf-lib/fontkit(PDF 수정·글꼴 삽입)을 사용합니다. 기존 Mac 앱의 제목 제외·중복 제거·머리말 제거 규칙을 TypeScript로 이식했습니다.

개별 의존성의 라이선스와 Nanum Gothic 글꼴·Tesseract 모델 라이선스는 빌드 자산의 `licenses/`와 `vendor/licenses/`에 포함합니다. 공개 저장소에는 합성 테스트 코드만 포함하며 실제 문헌은 포함하지 않습니다.

검증 결과와 실제 문헌 검증 방법은 [VALIDATION.md](VALIDATION.md)를 참고하세요.

배포 주소에서 테스트하려면 `PDF_BASE_URL=https://cloudmate37.github.io/pdf/ pnpm test:e2e`를 사용하세요. 검증용 합성 문서도 브라우저 안에서만 처리됩니다.
